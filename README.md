# GPT龙娘 · 自定义宠物分享包

这个包包含 GPT小龙的透明动画图集（`spritesheet.webp`）、本地宠物元数据（`pet.json`）和动作预览（`preview.png`）。图集为 v2 格式：1536 × 2288 像素，8 列 × 11 行，包含 9 组动作和 16 个视线方向。

## 给 ChatGPT 桌面版 / Codex 用户

克隆到本地把 `pet.json` 和 `spritesheet.webp` 放入自己电脑的 `~/.codex/pets/gpt-xiaolong/` 目录（Windows 为 `%USERPROFILE%\.codex\pets\gpt-xiaolong\`），再在 **Settings → Pets** 刷新。
